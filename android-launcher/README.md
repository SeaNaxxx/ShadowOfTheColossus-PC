# Shadow of the Colossus Android launcher

This directory builds the Android APK. It imports the user's extracted game folder, runs the
repository's image-preparation scripts on device, and starts the ARM64 native loader in SDL's
Android activity.

## Build

Install JDK 17, Android SDK Platform 37, NDK 29.0.14206865, CMake, Ninja, Python 3, the host
Vulkan SDK (`glslangValidator`), and the GPU build's host header packages, then run:

```sh
./gradlew :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

The APK build cross-builds FEXCore, SDL3, fmt, xxHash, FFmpeg, Zydis, and the native loader for
arm64-v8a, then packages their shared libraries. The GPU build also needs the host-side Boost,
robin-map, and Vulkan Memory Allocator headers. Set `SOTC_HOST_PREFIX` if those CMake packages
are outside the standard search paths. The native runtime can be built separately with
`bash tools/android/build_android.sh` from the repository root.

## Import game data

First, use a PS4 PKG Extractor app to extract your own game PKG. Then select the resulting
`CUSA08809` base-game folder in this launcher. It verifies `eboot.bin`, `sce_sys/param.sfo`, title
ID `CUSA08809`, and EU version `01.01`, then copies the folder into app-specific storage under
`Android/data/org.sotc.android/files/SotC/game`. PKG extraction is handled by that separate app;
this launcher imports the extracted game folder.

Sound is optional. Select `libSceNgs2.sprx` and `libSceUlt.sprx` from your own decrypted console
system modules. They are stored in the adjacent `sys_modules` folder. Neither game nor Sony files
are included in the APK.

The Play button runs image preparation before opening the native runtime. This is a bring-up path:
the CPU backend, GPU surface, and game execution have not yet been validated on an Android device.
A successful APK build does not establish that the game can run on Android.

The Gradle wrapper scripts in this directory are generated by Gradle and carry their upstream
Apache-2.0 notices in the script headers.
