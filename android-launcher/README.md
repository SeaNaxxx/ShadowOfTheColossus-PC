# Shadow of the Colossus Android launcher

This directory builds the Android APK. It currently provides a first-run data importer; it does
not yet contain the ARM64 game runtime or a game launch path.

## Build

Install JDK 17 and Android SDK Platform 37, then run:

```sh
./gradlew :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

## Import game data

On first launch, select the extracted `CUSA08809` base-game folder itself. The launcher verifies
`eboot.bin`, `sce_sys/param.sfo`, title ID `CUSA08809`, and EU version `01.01`, then copies the
folder into app-specific storage under `Android/data/org.sotc.android/files/SotC/game`.

Sound is optional. Select `libSceNgs2.sprx` and `libSceUlt.sprx` from your own decrypted console
system modules. They are stored in the adjacent `sys_modules` folder. Neither game nor Sony files
are included in the APK.

The app intentionally does not offer a Play button until the Android CPU, graphics, and native
game-call path are integrated. A successful APK build only validates this launcher package; it
does not establish that the game can run on Android.

The Gradle wrapper scripts in this directory are generated by Gradle and carry their upstream
Apache-2.0 notices in the script headers.
